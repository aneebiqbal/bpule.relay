## 5. Migration ownership

Every site is owned by exactly one of:

| Owner | What it means |
|---|---|
| **store** | Already behind `ScoutStore` — a Neon store implementation covers it with no call-site change |
| **repo** | Direct client use in a domain module — becomes a method on a domain repository (`src/lib/db/repos/*`) |
| **route** | API route — server-side, becomes a repository call |
| **client** | Browser-side — must move behind a server loader / route handler |
| **system** | Cron / service-role — needs its own Neon service connection |
